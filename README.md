# Be My Wife

This project is a romantic proposal website made to say "I love you" and invite the love of my life to become my wife.

## Project Structure

```
bemywife
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── components/
│   ├── header.html
│   └── wife-card.html
├── data/
│   └── messages.json
├── images/
├── package.json
├── README.md
└── .gitignore
```

## Getting Started

1. Clone the repository.
2. Open the project folder in a local web server.
3. Visit `http://localhost:8000` in the browser.

## Run locally

```bash
npm install
npm start
```
